Подключённые порталы

Сообщения из подключенных порталов будут приходить в отдельный чат на вашем портале.

Отличительное название портала, чтобы вы понимали, с какого портала пришло сообщение.
Общий чат — «Сборщик сообщений» (один на все порталы). Отдельный чат — «Сборщик сообщений: {Название портала}».
Как создать вебхук на портале-источнике:
  1. Раздел «Разработчикам» → «Другое» → «Входящий вебхук»
  2. В разделе настройка прав выберите следующие права: Чат и уведомления (im), Открытые линии (imopenlines) и Пользователи (user)
  3. Скопируйте выданную ссылку целиком, вместе со слэшем на конце
  4. Нажмите кнопку создать
